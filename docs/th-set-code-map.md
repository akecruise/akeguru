Only CONFIRMED rows are wired into `th.ts`.

Tested tickers: PTT (energy), GULF (energy/utilities), KTB (bank). **Real coverage gap found**: every other large-cap general-commercial ticker tried (CPALL, ADVANC, AOT, HMPRO, CRC, BJC, CPN, TRUE) returned no financial_statement data at all via this API (204 for every year 2017-2024) despite existing in the company directory — GULF was the only substitute with real data. This API's financial_statement coverage is sparse; th.ts will only produce ก.ล.ต.-sourced facts for tickers that happen to have data published, and falls back to Yahoo-only for the rest (see warnings in ingest.ts output). Tolerance: candidate/anchor ratio in (0.85, 1.15).
